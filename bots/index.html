Тринадцать ботов. Три платформы.

Нажимайте на кнопки в телефонах — это интерактивные демо. Для каждой платформы свой вид: карточки Discord, быстрые ответы WhatsApp, инлайн-кнопки Telegram. Сценарии из этих же файлов запускаются как настоящие боты.

Как запустить настоящего бота1. Telegram: создайте бота у @BotFather и получите токен.
2. pip install -r code/requirements.txt
3. BOT_TOKEN=ваш_токен python code/bot.py nova — Telegram (nova, basil, cura, pulse, altair, signal)
   python code/discord_bot.py dc-pixel — Discord · python code/whatsapp_webhook.py wa-nomad — WhatsApp (нужен Meta Business)
Тексты и кнопки лежат в code/scripts.json — меняйте под свой бизнес.
